# 直接 ConvLSTM 可信基线（T=10，seed=42）

本目录保存重构训练流程后的第一个可复现实验。它不是最终模型，而是后续所有改进的统一比较起点。

## 实验目的

老师提供的旧代码可以展示 ConvLSTM 流程，但数据排序、陆地填充值、数据划分和指标口径会影响结论。本实验首先建立一个严格基线：在相同日期划分、海洋掩码和物理单位下，判断直接 ConvLSTM 能否超过 persistence。

## 实验设置

| 项目 | 设置 |
| --- | --- |
| 数据 | 2020 年 366 张日尺度 SST 网格 |
| 任务 | 前 10 天预测下一天 |
| 样本数 | 训练 246 / 验证 73 / 测试 37 |
| 模型 | 两层 ConvLSTM，隐藏通道 `[16, 16]` |
| 预测方式 | 直接生成完整下一日海温场 |
| 归一化 | 仅使用训练期拟合的全局 Min-Max |
| 损失和指标 | 只统计有效海洋格点 |
| 优化器 | Adam，学习率 0.001，batch size 4 |
| 训练 | 最多 200 轮，早停 patience 20，AMP |
| 最佳轮次 | 160 |

## 测试结果

| 指标 | 直接 ConvLSTM | Persistence |
| --- | ---: | ---: |
| RMSE | 0.284106 ℃ | **0.276034 ℃** |
| MAE | 0.188126 ℃ | **0.181800 ℃** |
| Skill | **-2.92%** | 0% |

模型能够复现大尺度海温分布，因此预测图与真实图看起来很像；但 RMSE 比直接复制最后一天高约 2.9%，不能说明模型学到了有用的次日变化。

老师旧代码曾报告 RMSE 0.7186，但它采用了不同的数据划分和评估实现，并把填 0 的陆地计入误差，不能与本实验直接比较。在旧协议下重新计算 persistence 也会得到不同数值，因此后续实验统一使用本目录的海洋格点评估协议。

## 本实验得到的经验

1. 海温相邻日高度相似，persistence 是必须比较的强基线。
2. 仅凭三张海温图“看起来差不多”无法判断模型是否有效。
3. 直接生成完整海温场会让网络把大量能力用于复制最后一天，而不是学习微小变化。
4. 下一步应改为残差预测：`下一日 = 最后一天 + 预测变化量`。
